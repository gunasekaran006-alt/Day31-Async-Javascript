# Dynamic Product Catalog 🛒

A lightweight, responsive product listing page built with **HTML5**, **Bootstrap 5**, and **Vanilla JavaScript**. This project demonstrates the use of **Asynchronous JavaScript** to fetch and display data from an external REST API.

## 🚀 Features
- **Asynchronous Data Fetching:** Uses the [Fetch API](https://developer.mozilla.org) with `async/await` for clean, non-blocking code.
- **Dynamic UI:** Products are rendered dynamically using JavaScript DOM manipulation.
- **Responsive Design:** Built with [Bootstrap 5](https://getbootstrap.com) to ensure a seamless experience on mobile, tablet, and desktop.
- **Error Handling:** Includes `try...catch` blocks and HTTP response validation for a robust user experience.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Scripting:** JavaScript (ES6+)
- **API:** [FakeStoreAPI](https://fakestoreapi.com)

## 📂 Project Structure
- `index.html`: The main structure and Bootstrap integration.
- `script.js`: Logic for fetching API data and rendering cards.
- `README.md`: Project documentation.
